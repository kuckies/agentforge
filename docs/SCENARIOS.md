# Свои сценарии

На вкладке «Проверка» загрузите JSON-файл. На вкладке «Сравнение» можно загрузить тот же файл для обоих вариантов. Скачайте встроенный набор кнопкой «Скачать сценарии» как образец.

Поддерживаются массив сценариев и объект `{"scenarios": [...]}`. Файл должен быть в UTF-8 (BOM допустим), размером до 1 МБ. Лимит — 100 сценариев, до 20 шагов в одном диалоге. Файл отчёта со списком results не является файлом сценариев.

```json
[
  {"id":"math","prompt":"Сколько будет 2+2? Ответь только цифрой.","expected":"4","check":"exact"},
  {"id":"status","prompt":"Верни только JSON с полем status равным ok.","expected":"{\"status\":\"ok\"}","check":"json","output_format":"json"}
]
```

`id` — уникальная непустая строка. `prompt` и `expected` — непустые строки. `expected` остаётся строкой даже для JSON. Проверки:

- `exact`: полное совпадение, включая регистр и пробелы.
- `substring`: вхождение без учёта регистра; используется по умолчанию.
- `json`: совпадение разобранных JSON-значений; порядок ключей объекта не важен, порядок массивов важен. true не равно 1.

`output_format: json` отдельно включает формат генерации JSON. Он не подставляет ожидаемый ответ и не гарантирует правильное содержание. Демо не управляет форматом генерации; используйте для него стандартные три сценария.

Диалоги учебного бота:

```json
[{"id":"order-dialogue","steps":[
  {"prompt":"Где мой заказ?","expected":"Укажите номер заказа","check":"substring"},
  {"prompt":"AF-1001","expected":"shipped","check":"substring"}
]}]
```

Каждый сценарий начинает новый разговор; его шаги используют одну сессию. Весь сценарий успешен, только если успешны все шаги. Диалоги доступны для режима учебного бота, а сравнение моделей использует отдельные запросы.

«Сложные диалоги — 12» — 32 шага о возвратах, потерянных заказах, оплате, смене посылки, забывании номера и противоречивых просьбах. Файл: `scenarios-support-hard.json`. Для запуска откройте `Start-TestBot.cmd`, выберите «Бот поддержки (учебный)» → «Сложные диалоги — 12» → «Запустить тесты». Результат сохраняется в «Истории»; JSON-отчёт можно скачать.

Бот сохраняет заказ после обычного вопроса или благодарности. Явная просьба забыть номер очищает заказ и ожидание номера; вопрос о другой посылке требует нового номера. Это память текущей сессии, а не изменение учебной базы заказов.

«Контрольные диалоги — 20» проверяют отрицания, следующую посылку, уточнение номера обычной фразой, опечатки и навязывание категории. Набор содержит 49 шагов и хранится в `scenarios-support-control.json`. После исправлений support-v4 проходит все 20 диалогов. Результаты обеих версий сохранены в [разборе проверки](SUPPORT-CONTROL.md).

После загрузки файл можно править в раскрывающемся редакторе. Повторная отрисовка страницы не перезаписывает правки. «Вернуть встроенный набор» отменяет импорт; переключение набора загружает его примеры, поэтому заранее скачайте свои правки. Импортированный JSON обрабатывается как данные и не исполняется как код.
