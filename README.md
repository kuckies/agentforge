# AgentForge 0.1.0-rc1

Локальное приложение для проверки ИИ-агентов: запустите набор задач, найдите ошибки, сравните две модели или инструкции и сохраните результат. Windows 11, Python 3.14 x64. Это кандидат первой версии для проверки перед выпуском.

Local Windows app for testing AI agents and comparing models or instructions. Includes JSON scenarios, conversation tests, SQLite history, and a free offline demo.

[Пример ForgeShop: сложные диалоги улучшены с 8/12 до 12/12](docs/FORGESHOP-CASE.md). В интерфейсе: «Бот поддержки (учебный)» → «Сложные диалоги — 12».

[Контрольные диалоги ForgeShop выросли с 14/20 на support-v3 до 20/20 на support-v4](docs/SUPPORT-CONTROL.md). В интерфейсе выберите «Контрольные диалоги — 20».

## Начать

На подготовленном компьютере дважды щёлкните **Start.cmd**. В браузере откроется http://127.0.0.1:8501.

Если приложение уже работает, просто откройте этот адрес. Для остановки используйте **Stop.cmd**. После замены файлов версии остановите приложение, запустите снова и обновите страницу.

1. Оставьте вкладку **Проверка** и агента **Демо (бесплатно)**.
2. Нажмите **Запустить тесты**. Ожидается **3/3**.
3. Скачайте отчёт или откройте **История** — он уже сохранён.

Для первого запуска из распакованного архива сначала установите обычный Python 3.14 x64, затем откройте **Setup.cmd**, дождитесь завершения и откройте **Start.cmd**. Интернет нужен для загрузки Python-пакетов. Права администратора, изменения политики PowerShell и платные подписки не требуются. Демо не требует моделей и ключей.

## Четыре вкладки

- **Проверка:** встроенные задачи или ваш JSON-файл; локальные модели, свой агент, Ollama или учебный бот.
- **Сравнение:** две модели с одной инструкцией либо две инструкции одной модели, один фиксированный набор для обеих сторон.
- **История:** сохранённые проверки и сравнения, ответы, параметры и скачивание отчётов.
- **Помощь:** первый запуск, подключение агента и объяснение результатов.

Подробные JSON-редакторы и настройки спрятаны под раскрывающимися разделами. Сценарии можно скачать как образец, загрузить обратно и отредактировать. Ошибочный файл не запускается. Лимиты: 1 МБ на файл, 100 сценариев, 20 шагов в диалоге. [Формат сценариев и примеры](docs/SCENARIOS.md).

## Подключить агента

Выберите **Свой агент**, запустите свой сервер на этом ПК и укажите адрес, модель и протокол: OpenAI-совместимый или Ollama. Поддерживаются loopback-IP 127.0.0.1 и ::1; имя localhost замените на 127.0.0.1. Полный пример запроса и ответа: [docs/API.md](docs/API.md).

На подготовленном компьютере доступны Qwen 0.5B, 1.5B и 7B. Режим **Локальная модель** и сравнение запускают уже установленные файлы на время проверки. Процессы, которые работали до проверки, сохраняются; созданные проверкой завершаются. Если адрес/модель в настройках изменены вручную, нужен самостоятельно запущенный сервер.

Архив **не включает** модели, движок llama.cpp и Python-окружение. Для переноса моделей нужна соседняя папка AgentForge-Runtime; [её структура и источники](docs/MODELS.md). Расположение:

```text
папка/
  AgentForge-Starter/
    Start.cmd
    app.py
  AgentForge-Runtime/
    llama/llama-server.exe
    models/...
```

## Учебный бот

Откройте **Start-TestBot.cmd**. Он использует уже запущенную Qwen 7B либо запускает установленную модель. Дождитесь адреса http://127.0.0.1:8085, затем откройте его для разговора. В AgentForge выберите **Бот поддержки (учебный)** и набор одиночных обращений или диалогов.

Пример: «Где мой заказ?» → «AF-1001» → «А трек-номер?». Бот использует вымышленные заказы и заданную учебную политику. Qwen определяет категорию обращения; чтение заказов и ответы выполняются кодом. Реальные заказы, платежи и обращения не изменяются. В чате есть «Новый разговор». До 256 разговоров, память в RAM до 30 минут неактивности; перезапуск очищает её. После обновления кода остановите старое окно через Ctrl+C и снова откройте Start-TestBot.cmd.

## Хранение и проверки

История находится в **data/agentforge.sqlite3**. Для резервной копии закройте приложение и скопируйте data. База и тестовые журналы не входят в архив исходников. Результаты не загружаются в облачное хранилище; запросы агентов идут на выбранные локальные серверы. Локальные серверы пользователя могут иметь собственное поведение — проверьте их настройки.

**Test.cmd** запускает автоматические тесты без моделей, ключей и платных сервисов. Тестовые базы временные. [Как проверить сборку](docs/TESTING.md).

Баллы относятся к конкретным задачам, а не к общему качеству модели. Провал означает несоответствие ожидаемому ответу; техническая ошибка означает сбой запроса или выполнения. Время зависит от прогрева, кэша и нагрузки. Сравнение последовательно выполняет A, затем B. Семантического ИИ-судьи, облачных API-ключей и многопользовательской авторизации в этой версии нет.
