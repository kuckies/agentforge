# Проверка 0.1.0-rc1

Дата: 10 ноября 2026. Windows 11, CPython 3.14 x64.

Подтверждено:

- 48 автоматических тестов проходят из исходной папки и из распакованного архива.
- Архив распакован в новую изолированную папку; создано новое .venv и установлены только requirements.txt из сборки.
- `pip check` не обнаружил повреждённых зависимостей.
- В распакованной папке нет соседнего AgentForge-Runtime; демо работает без моделей и показывает 3/3.
- Реальный HTTP-сервер чистой сборки отвечает HTTP 200, health возвращает ok; после проверки он остановлен.
- В браузере проверены обновлённый экран, четыре вкладки, запуск демо 3/3, сохранённый результат, история и справка.
- Импорт одного пользовательского JSON-сценария проверен через интерфейс с настоящей Qwen 7B: 1/1, отчёт сохранён в истории. Сам файл для этого автоматизированного интерфейсного теста передан тестовым объектом загрузки; ручной выбор файла в диалоге браузера отдельно не проверялся.
- Импорт, неверные файлы, сохранение ручных правок, собственный локальный API и общий файл для сравнения покрыты тестами на локальных подставных серверах.
- Команда Stop.cmd проверена на работающем экземпляре приложения. Текущая пользовательская база сохранена; модель не останавливалась обновлением интерфейса.

Браузерная проверка обнаружила устаревший импорт в старом работающем процессе. Перезапуск приложения загрузил новые модули. При обновлении файлов рекомендуется Stop.cmd, затем Start.cmd, после этого обновление страницы.

Архив не содержит .venv, data, пользовательскую SQLite, модели и движок. Лицензия MIT относится к исходному коду проекта; сторонние зависимости и модели имеют собственные условия. Публикация в GitHub и публичный релиз не выполнялись.

**Второй физический компьютер не проверен.** Чистое окружение на нынешнем ПК не заменяет проверку на другом оборудовании. Это кандидат версии 0.1, а не подтверждение готовности ко всем конфигурациям Windows. Следующий этап — установка на другом ПК по README и фиксация результата.
