# 0.1.0-rc1 — 10 ноября 2026

Первая локальная сборка для проверки перед выпуском.

- Вкладки «Проверка», «Сравнение», «История», «Помощь».
- Загрузка и скачивание JSON-сценариев: UTF-8, до 1 МБ; проверка структуры до запуска.
- Подключение своего локального агента по OpenAI-совместимому API или Ollama.
- Автозапуск уже установленных Qwen для проверки и сравнения.
- Сравнение двух моделей или инструкций с одной кнопки; экспорт и история в SQLite.
- Учебный бот ForgeShop с отдельными сессиями и многошаговыми тестами.
- Инструкция первого запуска, примеры API, тесты, лицензия MIT для исходного кода проекта.

Модели, движок llama.cpp, окружение Python и пользовательская база не включены в архив. Демо работает без моделей и ключей. Проверка установки в чистой папке выполняется на нынешнем ПК; второй физический компьютер ещё не проверен. Репозиторий GitHub создан с закрытым доступом; публичный релиз не опубликован.
