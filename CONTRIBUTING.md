# Участие в AgentForge

Версия 0.1.0-rc1 предназначена для локальной Windows-разработки. Проверенная среда — Windows 11, CPython 3.14 x64. Первый запуск: Setup.cmd → Start.cmd. Демо не требует моделей или ключей.

## Изменения кода

1. Опишите конкретную проблему и ожидаемое поведение.
2. Сделайте небольшое изменение, сохранив существующий формат сценариев и отчётов.
3. Добавьте проверку нового поведения, если она нужна для защиты от повторения ошибки.
4. Запустите Test.cmd. Для интерфейсных изменений дополнительно проверьте соответствующее действие в браузере.
5. В описании изменений укажите проблему, полученное поведение и проверку результата.

Автоматические тесты используют временные базы и подставные локальные серверы; они не должны запускать платные API, скачивать модели или менять пользовательскую историю. Настоящие модели проверяются отдельно. Строгость оценок не ослабляется ради улучшения баллов. Изменение системной инструкции и изменение условий теста нужно различать в отчётах.

## Файлы проекта

Исходники, встроенные вымышленные сценарии и документация входят в репозиторий. .venv, data, отчёты пользователя, .env и файлы моделей исключены через .gitignore. Новые зависимости добавляйте только при необходимости, после чего проверьте установку из чистой папки.

## Сообщения об ошибках

Укажите версию из VERSION, версию Python, шаги воспроизведения и ожидаемый результат. Воспроизведение на демо или вымышленном сценарии предпочтительнее частных данных. Не включайте ключи доступа, пароли и содержимое личной базы.

Исходный код проекта распространяется по MIT; условия сторонних моделей и пакетов указаны у их издателей.
