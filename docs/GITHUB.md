# Подготовка репозитория GitHub

Репозиторий: [kuckies/agentforge](https://github.com/kuckies/agentforge). Ветка — main. Доступ пока закрытый. Пароли и токены не включаются в исходники; автор Git настраивается только для этого проекта и использует адрес GitHub noreply.

## Что подготовлено

- README с первым запуском, описанием возможностей и ограничений.
- Лицензия MIT, CHANGELOG и CONTRIBUTING.
- Формы сообщения об ошибке и предложения улучшения, шаблон pull request.
- GitHub Actions для проверки на Windows с Python 3.14: установка requirements.txt, pip check и автоматические тесты без моделей.
- .gitignore исключает пользовательскую историю, окружение, журналы, файлы моделей и .env.
- .gitattributes задаёт переносы строк для Python и Windows CMD.

Действия checkout и setup-python закреплены за конкретными коммитами официальных репозиториев; версии указаны в комментариях workflow. Источники: [actions/checkout](https://github.com/actions/checkout), [actions/setup-python](https://github.com/actions/setup-python).

## Автор и подключение

Автор взят из подтверждённого профиля владельца GitHub. Использован адрес noreply, соответствующий ID и имени аккаунта; глобальные настройки Git не менялись. При работе с другой копией проекта настройте свои имя автора и подтверждённый адрес GitHub либо noreply.

В этой папке не сохраняются пароли или токены GitHub. Для загрузки нужен вход в ваш аккаунт через подключение GitHub или штатный способ авторизации Git. Видимость будущего репозитория — отдельный выбор владельца; публичная публикация автоматически не выполняется.

Для новой копии проекта локальные команды из папки проекта:

```powershell
git config --local user.name "Ваше имя автора"
git config --local user.email "Ваш подтверждённый GitHub email или noreply"
git status --short
git diff
```

Кавычки содержат поля для заполнения, а не готовые персональные данные. В подготовленной рабочей папке origin указывает на существующий репозиторий. Изменения добавляются в коммит после просмотра diff, затем отправляются через git push. Не создавайте параллельную начальную историю на сервере.

## Статус проверки

GitHub Actions проверяет загрузки main и pull request; фактический статус виден на вкладке Actions репозитория. Подготовленный workflow использует Windows и Python 3.14. Локальные проверки и чистая установка описаны в docs/RELEASE_CHECK.md. Проверка на втором физическом ПК по-прежнему не выполнена. Модели и SQLite пользователя не должны попадать в репозиторий или архив исходников.
