# Подключение своего агента

На вкладке «Проверка» выберите «Свой агент». В версии 0.1 поддерживаются локальные HTTP-серверы с числовым loopback-IP: 127.0.0.1 или ::1. Выберите протокол и укажите полный адрес маршрута и имя модели. Облачные API, произвольные внешние адреса и API-ключи в этой версии не настраиваются.

## OpenAI-совместимый сервер

Пример адреса: `http://127.0.0.1:8080/v1/chat/completions`.

Запрос:

```json
{"model":"my-agent","messages":[{"role":"system","content":"Инструкция"},{"role":"user","content":"Вопрос"}],"stream":false,"temperature":0,"seed":42,"max_tokens":128}
```

Ожидаемый ответ:

```json
{"choices":[{"message":{"content":"Ответ агента"}}]}
```

Для JSON-сценария добавляется `response_format: {"type":"json_object"}`. Сервер должен поддерживать этот параметр. Это совместимый протокол локального сервера, а не вызов облачного API OpenAI.

## Ollama

Адрес: `http://127.0.0.1:11434/api/generate`. Модель должна быть заранее установлена в Ollama. Запрос содержит model, prompt, system, stream=false и options; ожидается строка в поле response. Для JSON-сценария добавляется `format: "json"`. Ollama не входит в установку приложения.

## Учебный бот

`Start-TestBot.cmd` запускает отдельный сервер на 8085. `POST /chat` принимает message и необязательный session_id, возвращает intent, reply, order и session_id. `/reset` выдаёт новую сессию. `/v1/chat/completions` совместим с одиночными проверками и обрабатывает каждый запрос независимо. Серверная политика не заменяется клиентской системной инструкцией.

Если API вашего агента устроен иначе, добавьте адаптер по образцу agents.py и проверьте его на локальном подставном сервере. Встроенный предел ответа — 1 МБ; тайм-аут задаётся в интерфейсе, автоматических повторов запросов нет.
