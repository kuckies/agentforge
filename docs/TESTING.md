# Проверка сборки

Запустите `Test.cmd` либо из папки проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

Автоматические тесты проверяют движок, интерфейс, HTTP-адаптеры на подставных серверах, историю SQLite, атомарность сравнений, память диалогов и импорт файлов. Они не требуют моделей, API-ключей или платных сервисов; базы для тестов временные.

Проверка первого запуска: откройте Start.cmd → «Проверка» → «Демо» → «Запустить тесты». Ожидается 3/3, новый результат должен появиться во вкладке «История». Скачайте сценарии, измените expected и загрузите обратно; провал должен отобразиться в результате.

На новом ПК проверяйте сначала демо. Архив исходников не содержит AgentForge-Runtime: подключение моделей проверяется после отдельной подготовки движка и файлов модели. Встроенные сценарии не доказывают качество агента на произвольных задачах.
